# Andrew Charabin Portfolio

A static portfolio site built with HTML, CSS, and JavaScript. GitHub Pages serves the site from the repository root; no build step is required.

## Content

- `index.html` is the main portfolio page.
- `projects/projects.json` supplies the project cards on the home and projects pages.
- `skills.json` supplies the skills list.
- `experience/` contains the standalone career timeline.
- `assets/` contains styles, scripts, images, audio, and the resume PDF.

For local preview, run `python -m http.server 8000` from the repository root and open `http://localhost:8000/`.
